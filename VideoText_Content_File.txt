3. CORE PRODUCT — WHAT IT DOES
================================================================================

VideoText.io is built around 7 core tools that handle every stage of video text
production. These are not standalone features — they're an integrated pipeline.

  1. VIDEO → TRANSCRIPT
     The flagship. Upload any video (or paste a YouTube URL) and get back a full,
     accurate, timestamped transcript. Optional: summary, chapters, speaker
     identification, glossary enforcement, multi-language translation. Exports in
     TXT, PDF, DOCX, and JSON. Powered by OpenAI Whisper (large-v3 model) —
     the most accurate speech-to-text model available.

  2. VIDEO → SUBTITLES
     Generate professional SRT or VTT subtitle files from any video. Multi-language
     support: get 2, 5, or 10 languages simultaneously (based on plan) in a single
     ZIP download. No sequential waiting — all languages processed in parallel.

  3. TRANSLATE SUBTITLES
     Upload an existing SRT or VTT file (or paste the text) and translate it into
     any of 70+ languages while perfectly preserving the timing and formatting.
     Ideal for localizing existing subtitle libraries.

  4. FIX SUBTITLES
     Automatically repair broken subtitle files — timing drift, overlapping cues,
     grammar errors, incorrect line breaks, filler words. The tool returns a fixed
     file plus a detailed warnings list so you know exactly what was corrected.

  5. BURN SUBTITLES
     Hardcode subtitles permanently into a video. Upload the video + SRT/VTT file,
     and get back an MP4 with captions baked in — no player required to display them.
     Essential for social media, reels, and client deliverables.

  6. COMPRESS VIDEO
     Reduce video file size without visible quality loss. Choose from web, mobile,
     or archive compression profiles. Optional GPU acceleration for large files.
     Supports all major video formats.

  7. BATCH PROCESS
     Process 20 to 100 videos in a single job (Pro and Agency/Business plans).
     Upload multiple files, set your options once, and download a ZIP with all
     outputs. Every file processed in parallel — not one after another.
