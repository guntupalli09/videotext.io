# Rev style guide transcript formatter: map rough AI text to payout rules

A **Rev style guide transcript formatter** search usually means one job: get rough text into reviewer-shaped paragraphs with the right verbatim mode, bracket tags, timestamps on inaudibles, and cautious speaker cues before you skim audio. VideoText splits capture from checklist work — finish audio in [Video → Transcript](https://videotext.io/video-to-transcript), then carry the paste into [Format → Client guidelines](https://videotext.io/guideline-format) where the editable Rev-aligned cards track what changed from defaults.

## Preset workflow most freelancers run

1. Export the transcript with whichever timestamps you need for the job.
2. Use **Make this client-ready →** on the result page so the text loads in the guideline workspace.
3. Select the Rev preset and read each rule card next to the platform PDF you were assigned.
4. Edit card text only where your client brief diverges; keep the “Edited” badges — they show reviewers what you overrode.
5. Run your listen pass with the cards side by side, then log disputes with the same wording you saved.
